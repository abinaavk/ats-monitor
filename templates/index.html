Automatic setup on a Global server

          
Run one command on the Global server. It installs the API service and adds the tunnel route for you, then proves both work. Monitor never runs commands on a Global itself.

          

            
Done for you
    
              
  • Writes and enables the systemd service for the Global API, then starts it.
    • 
              
  • Adds your-api-host /v1/request → 127.0.0.1:9997 to your Cloudflare config, keeps every other route and restarts cloudflared once.
    • 
              
  • Validates the config and service file first, checks the Monitor adapter, and restores the previous files if anything fails.
    • 
              
  • Verifies signed health on the server itself and over the public HTTPS address.

            
You provide first
    
              
  • A running Cloudflare tunnel managed with a config file (dashboard/token tunnels need the route added in Cloudflare).
    • 
              
  • The tunnel’s DNS record for the API hostname.
    • 
              
  • An HTTPS API address on the standard port, set when you run server configure.
    • 
              
  • Python with Flask for the adapter. Setup names the exact package if it is missing.

          

          

            
First time only: name this Global and set its API address
sudo python3 app.py server configure --role global --name 'My Global' --api-domain https://api.example.com

            
Install the service and tunnel route (add --install-monitor if Monitor is not on that server yet)
sudo python3 app.py server setup --apply --install-monitor

            
Check everything at any time
sudo python3 app.py server doctor

Troubleshooting: what the messages mean
          
MessageFix

            
rejected the server ID or passkeyThe saved key is out of date. Open that server’s Update ID and passkey and paste its current pairing file.

            
Clock mismatchTurn on time sync on both servers: timedatectl set-ntp true.

            
has no /v1/request routeOn that Global run sudo python3 app.py server setup --apply.

            
unreachable through its tunnelThe Global daemon or cloudflared is stopped. On that Global run sudo python3 app.py server doctor.

            
Cloudflare blocked the requestAllow this server for /v1/request in Cloudflare security rules (WAF, Bot Fight Mode).

            
Monitor adapter is not configured / module is missingOn that Global run setup again, or install the named Python module for its interpreter.

            
Cannot resolve / refused / certificateCheck the tunnel DNS record and that the address is the real HTTPS hostname.

          

          
For a full end-to-end check run sudo python3 app.py server doctor on this server (tests every Global) or on a Global (tests its service, tunnel route and adapter).
